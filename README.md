## Deploy to Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/praveenrajr14-cloud/faith-and-justice-associates)

### Render Deployment Instructions:
1. Click the **Deploy to Render** button above or visit [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** &rarr; **Static Site**.
3. Select this repository: `praveenrajr14-cloud/faith-and-justice-associates`.
4. Settings:
   - **Name**: `faith-justice-associates`
   - **Branch**: `main`
   - **Build Command**: *(leave blank)*
   - **Publish Directory**: `.`
5. Click **Create Static Site**.
   Render will deploy your site and give you a free live URL: `https://faith-justice-associates.onrender.com`.
